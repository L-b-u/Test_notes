# 02 · 编程能力

> ATE 岗写代码不是为了造软件，而是为了：**写测试程序、处理测试数据、自动化重复工作。**

## 待学清单

| 模块 | 内容 | 验收标准 | 状态 |
|---|---|---|---|
| C 语言 | 变量、判断循环、函数、数组、指针、结构体、位操作、文件读写 | 能读一个二进制测试结果文件并统计 | ⬜ |
| Python | 语法、函数、文件、异常、pandas/numpy、matplotlib | 能读测试 log、算良率、画 Shmoo 图 | ⬜ |
| Verilog/VHDL | 模块、赋值、时序逻辑、testbench 概念 | 能读懂一段 RTL，说出输入输出与时序 | ⬜ |
| Linux | 文件操作、grep/awk/sed、管道、shell 脚本、权限 | 能在 Linux 下跑脚本、批量处理 log | ⬜ |

## 优先顺序（时间有限时）

```
Python 数据处理  >  C 基础与位操作  >  Linux 命令  >  Verilog 读码
```

理由：日常工作中"处理数据、出报告、自动化"出现频率最高；Verilog 只需要读懂。

## 建议的练习项目（都能写进简历）

1. **测试数据处理器**：读 CSV/文本 log → 提取每颗芯片的测试项 → 算良率与 Cpk → 输出 Excel 报告。
2. **Shmoo 图工具**：给定二维扫描数据（VCC × 频率），用热力图画出 Pass/Fail 边界。
3. **自动测试脚本**：用 Python 驱动仪器（pyvisa）做一次电压扫描并记录。
4. **Pattern 解析器**：读一个简单的向量文件，统计翻转覆盖率。

## 代码规范（面试也会看）

- 变量名见名知意；函数单一职责；
- 关键步骤写注释，说明"为什么"而不是"做了什么"；
- 处理数据前先校验（空值、越界、单位）；
- 结果可复现：固定随机种子、记录输入文件版本。
