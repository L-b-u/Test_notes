# ATE 测试笔记 · Test_notes

> 为一个目标服务：**拿到 ATE 测试工程师的 offer，并且上手就能干活。**
>
> 路线：电子基础（模电 / 数电）→ 编程能力（C / Python / Verilog / Linux）→ 测试专业（DC/AC/功能、DFT、CP/FT/SLT、数据分析）→ ATE 平台实战（J750 / V93000）→ 项目与求职。
>
> 每篇笔记都按「能讲给别人听」的标准写：结论在前，推导在后，电路图和波形可对照，末尾有**自测题**和**一页速记卡**。

---

## 这个仓库怎么用

1. **按编号顺序读**：`00 → 06`，每个目录里的文件也按 `01、02…` 排序，编号就是学习顺序。
2. **先做题再看答案**：每篇的「自测题」用折叠块藏答案，先自己写再看。
3. **复习只看速记卡**：每篇最后一节是「一页速记卡」，考前 3 分钟刷。
4. **打勾推进度**：下面的进度看板每学完一章就勾一个。
5. **复习节奏**：当天 → +1 天 → +7 天 → +30 天，各篇末尾有「复习记录」表，学到哪记到哪。

## 写笔记的约定

每篇笔记固定这几节，方便复习时快速定位：

```
0. 先看结论        ← 一张表，复习只看这里
1. 电路 / 概念识别  ← 图 + 元件作用表
2. 静态分析
3. 动态分析        ← 推导链
4. 波形 / 数据对照表
5. 关键公式与参数
6. 与 ATE 测试的关联 ← 这一章在岗位上用在哪
7. 自测题          ← 折叠答案
8. 一页速记卡
9. 易错点清单
```

模板见 [00-学习路线/笔记模板.md](00-学习路线/笔记模板.md)。
