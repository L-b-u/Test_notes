## 我的复习方法

| 什么时候 | 做什么 |
|---|---|
| 当天学完 | 合上书，把这一章的电路画一遍、公式推一遍 |
| 第二天 | 只看「一页结论」，再自测一遍 |
| 第七天 | 只看「速记卡」，做自测题 |
| 第三十天 | 从零讲一遍给空气听，卡住的地方回去看 |

每篇末尾都有「复习记录」表，学一轮记一次。
