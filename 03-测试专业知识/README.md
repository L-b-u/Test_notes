# 03 · 测试专业知识

> 这一阶段决定你能不能"像测试工程师一样说话"。
> 面试里被问得最多的不是电路，而是：**DC 测试测什么？CP 和 FT 区别？Scan 是什么？**

## 一、测试分类

| 类别 | 测什么 | 典型测试项 | 对应仪器/资源 |
|---|---|---|---|
| **DC 参数测试** | 直流电平、电流、阻抗 | 阈值 VIL/VIH/VT、输出 VOH/VOL、输入漏电 IIL/IIH、电源电流 IDD/ICC、IDDQ、开路短路 | PMU / DC unit / DPS |
| **AC 参数测试** | 时间与频率特性 | 上升/下降时间、传播延迟 tPD、建立/保持、最大频率 fmax、增益、带宽、相位裕度、抖动 | 高速 digital pin + 比较器、AC 仪器 |
| **功能测试** | 逻辑功能是否正确 | Pattern 比对、真值表、状态机序列、通信协议 | Pattern memory + 驱动器 |
| **混合信号测试** | ADC/DAC 指标 | INL、DNL、SNR、THD、ENOB | 任意波形发生器 + 数字化仪 |

### DC 测试为什么重要

- 最快、最便宜、最能挡住坏片（开路、短路、漏电、ESD 损伤）。
- 通常在测试流程最前面做，先挡掉明显坏品，节省后面的测试时间。
- 关键技术：**PMU（参数测量单元）** 每个 pin 都能强制电压/电流并测量。

### AC 测试的关键概念

- **Shmoo 图**：两个变量（常为 VCC 与周期/频率）扫描，画出 Pass/Fail 边界，用来找"最快能跑多快、最低能在多少伏工作"。
- **Pin Margin**：把每个 pin 的时序/电平往边界推，看余量还有多少。
- **Guard band**：测试限值留的保护带，防止量测误差误杀好品。

## 二、DFT（Design for Test，可测性设计）

| 技术 | 原理 | 用途 |
|---|---|---|
| **Scan Chain** | 把内部触发器串成移位寄存器，测试时用 Pattern 移入/移出 | 检测内部逻辑的固定型故障（stuck-at） |
| **BIST** | 芯片内部自带测试电路（LFSR 产生激励、MISR 压缩响应） | 存储器、逻辑自测，降低 ATE 资源需求 |
| **Boundary Scan（JTAG, IEEE 1149.1）** | 在 IO 上加边界扫描单元，串成链 | 板级互连测试、无需探针即可访问内部 |

**为什么要有 DFT**：芯片内部节点在外部不可见，测试成本随复杂度指数上升；DFT 让"内部可观察、可控"。

## 三、三大测试阶段

| 阶段 | 何时 | 对象 | 设备 | 目的 |
|---|---|---|---|---|
| **CP**（Chip Probing / 晶圆测试） | 封装前 | 晶圆上的裸 die | 探针台 + ATE | 挑出坏 die，避免封装浪费 |
| **FT**（Final Test / 成品测试） | 封装后 | 封装好的芯片 | ATE + 分选机（Handler） | 保证出厂性能，分 bin |
| **SLT**（System Level Test） | FT 之后（部分产品） | 成品 | 板级/系统级测试台 | 模拟真实应用场景，抓 FT 漏掉的系统级问题 |

**成本逻辑**：CP 便宜（坏 die 不封装）、FT 贵（已封装）、SLT 更贵但更接近真实使用。越往后越贵，所以要把能挡的尽量往前挡。

## 四、数据分析

| 指标 | 含义 | 什么时候用 |
|---|---|---|
| **良率（Yield）** | 通过数 / 总数 | 日常监控、批次对比 |
| **Bin** | 失效分类（bin 1 = pass，其他为不同失效模式） | 定位主要失效模式 |
| **Cpk** | 工序能力指数，(USL−LSL)/6σ 与中心偏移的综合 | 判断测试限值是否合理、工艺是否稳定 |
| **SPC** | 统计过程控制，控制图监控漂移 | 产线异常预警 |
| **Shmoo** | 二维扫描的 Pass/Fail 图 | 找失效边界与余量 |
| **Wafer Map** | 晶圆上每颗 die 的结果分布 | 看失效是否与位置相关（边缘/中心） |

**Cpk 速记**：Cpk ≥ 1.33 一般认为工序能力足够；< 1.0 说明已经超出规格，随时可能批量失效。

## 五、术语速查

| 术语 | 含义 |
|---|---|
| DUT | Device Under Test，被测器件 |
| DIB / Load Board | 测试接口板 |
| Probe Card | 探针卡（CP 用） |
| Socket | 测试座（FT 用） |
| Test Program | 测试程序 |
| Test Plan | 测试计划/规范 |
| Pattern / Vector | 测试向量 |
| Timing Set | 时序配置（驱动沿、采样沿） |
| Levels | 电平配置（VIL/VIH/VOL/VOH 等） |
| PMU | 参数测量单元 |
| Guard band | 保护带 |
| Retest / Rework | 复测 / 返工 |
| OQC / IQC | 出货/来料检验 |
