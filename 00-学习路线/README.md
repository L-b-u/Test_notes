# 00 · 学习路线

> 目标岗位：**ATE 测试工程师（芯片测试）**。
> 这个文件回答三个问题：学什么、学到什么程度、怎么判断自己学到位了。

---

## 一、岗位到底要什么

ATE（Automatic Test Equipment）测试工程师的日常工作：

1. 拿到芯片的 datasheet 与测试规范（Test Plan）；
2. 在 ATE 平台上写测试程序（Test Program）：DC 参数、AC 参数、功能（Pattern）；
3. 调试：Shmoo、Pin Margin、时序与电平对齐；
4. 数据分析：良率、Cpk、失效 bin、SPC；
5. 与设计、封装、产线对接，定位失效原因。

所以需要三块能力，缺一不可：

| 能力 | 为什么需要 | 对应阶段 |
|---|---|---|
| **看得懂芯片内部** | 不理解为啥要测这一项，就写不出测试；失效了也不会分析 | ① 电子基础 |
| **写得动程序** | 测试程序本质是代码 + 时序 + 电平 | ② 编程能力 |
| **懂测试方法** | DC/AC/功能怎么测、DFT 怎么配合、数据怎么看 | ③④ 测试专业 + 平台 |

## 二、五阶段路线

### 第一阶段：电子基础（约 2～3 个月）

| 模块 | 要学的内容 | 验收标准 |
|---|---|---|
| 数字电路 | 逻辑门、组合逻辑、时序逻辑、触发器、状态机、存储器 | 给一个电路能写出真值表/输出波形；分得清组合与时序 |
| 模拟电路 | 二极管、三极管、放大电路、运放、AD/DA | 能算共射放大电路的 Q 点与增益；会用虚短虚断 |
| 半导体物理 | PN 结、MOS 管、CMOS 工艺 | 说得出 MOS 三个工作区、CMOS 反相器为什么省电 |
| 仪器 | 万用表、示波器、信号发生器、直流电源 | 会用示波器测幅值/频率/相位差；会设触发 |

> ⚠️ 这一阶段最容易犯的错：只看视频不动笔。**每个电路都要自己画一遍、算一遍**。

### 第二阶段：编程能力（约 1～2 个月，可与第一阶段并行）

| 模块 | 要学的内容 | 验收标准 |
|---|---|---|
| C 语言 | 变量、判断循环、指针、结构体、位操作、文件操作 | 能写一个读二进制/CSV 数据并统计的程序 |
| Python | 脚本、数据处理（pandas/numpy）、自动化测试 | 能读测试 log、画 Shmoo 图、批量出报告 |
| Verilog/VHDL | 能读懂 RTL（不必会设计） | 看懂一个 D 触发器/计数器的 RTL，理解测试向量从哪来 |
| Linux | 常用命令、shell 脚本、grep/awk/sed | 能在 Linux 下跑脚本、查 log |

> ATE 岗位里 Python 用得最多：**数据分析 + 自动化**。这是加分项，务必练到能独立写脚本。

### 第三阶段：测试专业知识（约 1～2 个月）

| 模块 | 要学的内容 | 验收标准 |
|---|---|---|
| 测试原理 | DC 测试、AC 测试、功能测试的原理与方法 | 说清每一项测什么、怎么判 Pass/Fail |
| DFT | Scan Chain、BIST、Boundary Scan（JTAG） | 说清 Scan 如何把内部节点"串出来"测 |
| 测试阶段 | CP（晶圆测试）、FT（成品测试）、SLT（系统级测试） | 说清三者的目的、设备、成本差异 |
| 数据分析 | Shmoo 图、良率分析、Cpk、SPC | 看到一张 Shmoo 图能说出失效边界在哪、可能原因 |

### 第四阶段：ATE 平台实战（约 2～4 个月）

| 模块 | 要学的内容 | 验收标准 |
|---|---|---|
| 平台选型 | 主流平台：Teradyne J750、Advantest V93000（入门推荐这两个） | 选定一个，装好仿真/IDE |
| 编程 | 测试程序结构、测试方法库、Pattern 生成、时序配置（Timing/Levels） | 能写出一支含 2～3 个测试项的 program |
| 调试 | Shmoo、Pin Margin、示波器联合调试 | 能定位一个"边界失效"，说出是时序、电平还是器件问题 |
| 没设备怎么办 | 培训机构实操课、厂商线上课程、仿真环境 | 至少跑通一次完整 flow |

### 第五阶段：项目实战与求职（约 1～2 个月）

- 做一个**完整的测试项目**：从测试方案设计 → 程序开发 → 调试 → 数据报告。
  没有真实芯片就用"一颗常见器件（如 74 系列逻辑门 / 运放 / LDO）+ 开发板 + 仿真"做。
- 简历：突出"技能 + 项目经验"，每个技能后面跟一句"用它做过什么"。
- 投递策略：优先第三方测试厂（机会多、上手快）→ 再考虑设计公司/IDM。
- 面试复盘：每次面完把问题记到 [06-面试题库](../06-面试题库/README.md)。

## 三、时间安排建议

| 时间 | 安排 |
|---|---|
| 工作日 | 1.5～2 小时：看视频 + 手推一遍 + 写笔记 |
| 周末 | 4～6 小时：整章复盘 + 做题 + 写代码 |
| 每两周 | 一次"讲给自己听"：把最近两章的内容合上书讲 10 分钟 |

**判断学到位没有的唯一标准**：能不能不看笔记，把这一章的电路画出来、公式推出来、讲给一个外行听懂。

## 四、常见坑

| 坑 | 后果 | 对策 |
|---|---|---|
| 只看视频不动笔 | 一考试/一面试就露馅 | 每个电路手画一遍、每题手算一遍 |
| 追求"学完"而不是"会用" | 学完就忘 | 用自测题验收，错了就回去补 |
| 模电死磕数学推导 | 时间不够、抓不住重点 | ATE 岗只需要"看得懂 + 会分析"，不需要设计 |
| 不碰真实数据 | 面试讲不出项目 | 用 Python 处理一次真实测试 log |
| 平台换来换去 | 哪个都不熟 | 咬定一个平台学透（J750 或 V93000） |
