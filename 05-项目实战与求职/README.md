# 05 · 项目实战与求职

## 一、一个能讲 20 分钟的项目长什么样

| 要素 | 内容 |
|---|---|
| 背景 | 选一颗常见器件（74HC 逻辑门 / 运放 / LDO / 小容量 SRAM）或一块开发板 |
| 测试方案 | 列出要测的参数、判据、测试条件（电压、温度、负载），写成一张 Test Plan 表 |
| 实施 | 在 ATE 仿真环境或"开发板 + 仪器"上实现，能跑通至少 3 个测试项 |
| 调试 | 至少记录一次故障定位过程（Shmoo / 边界扫描 / 波形分析） |
| 数据 | 采集 N 颗/N 次数据，做良率、分布、Cpk |
| 结论 | 哪些项是瓶颈、限值是否合理、如何改进 |

**关键**：项目不在"大"，在"闭环"——从需求到数据到结论，每步都说得出为什么。

## 二、简历要点

1. **技能栏写"会用"，不写"了解"**：每个技能后面跟一句用它做过什么。
   - ✅ "Python：处理 10 万条测试 log，生成良率与 Cpk 报告"
   - ❌ "熟悉 Python"
2. **项目描述用 STAR**：背景 → 任务 → 行动 → 结果（带数字）。
3. **突出测试相关关键词**：DC 测试、Pattern、Shmoo、Cpk、CP/FT、Scan、J750/V93000。
4. **一页纸**：应届/转行不要超过一页。

## 三、投递策略

| 顺序 | 目标 | 理由 |
|---|---|---|
| 1 | 第三方测试厂 / 封测厂 | 岗位多、上手快、能接触多类产品 |
| 2 | 设计公司（Fabless）的测试岗 | 更靠近设计与失效分析，要求更高 |
| 3 | IDM / 大厂 | 流程规范，但门槛高、竞争激烈 |

- 同一岗位可换关键词多投：ATE 测试工程师、测试开发、芯片测试、产品工程师（PE）、失效分析（FA）。
- 每次面试后 24 小时内写复盘（见 [06-面试题库](../06-面试题库/README.md) 的复盘表）。
