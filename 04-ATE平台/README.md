# 04 · ATE 平台实战

> 目标：**选定一个平台，能独立写出一支能跑的测试程序。**

## 一、主流平台

| 平台 | 厂商 | 特点 | 适合谁入门 |
|---|---|---|---|
| **J750** | Teradyne | 结构清晰、资料多、培训体系成熟，逻辑/混合信号 | ✅ 推荐入门 |
| **V93000** | Advantest | 模块化、高速数字与 SoC 强，市场占有率高 | ✅ 推荐入门（另一个方向） |
| ETS-800 | Eagle | 模拟/混合信号、电源类 | 做模拟测试再考虑 |
| Chroma 3650 | Chroma | 电源管理 IC 测试 | 电源方向 |

> 建议：**只选一个学透**。两个都会一点，不如一个能写完整程序。

## 二、一台 ATE 的组成（先建立整体图）

```
测试程序 ──> 时序(Timing) ──> Pin Electronics ──> DUT
                │                │
             电平(Levels)     比较器(Compare)
                                  │
                             结果(Pass/Fail) ──> 数据记录
```

| 概念 | 含义 | 类比 |
|---|---|---|
| **Test Program** | 测试流程与所有测试项的集合 | 一份体检套餐 |
| **Test Method** | 单个测试项的实现（函数） | 一项检查 |
| **Pattern** | 输入/期望输出的向量序列 | 检查项目的题目与标准答案 |
| **Timing Set** | 每个 pin 的驱动沿、采样沿 | 考试的时间安排 |
| **Levels** | VIL/VIH/VOL/VOH、比较阈值 | 及格线 |
| **PMU / DC unit** | 强制电压电流、测量 | 血压计 |

## 三、学习路径（4 步）

1. **看懂一支现成程序**：找一份官方 demo program，逐行读，标出每个测试项在干什么。
2. **改**：改限值、改时序、加一个 DC 测试项，跑通。
3. **写**：从零写一支包含 `connect → DC 测试 → 功能 Pattern → disconnect` 的程序。
4. **调**：人为制造一个失效（改限值/接错 pin），用 Shmoo 和 Pin Margin 找出来。

## 四、必会操作

- [ ] 建工程、选 DIB/引脚映射
- [ ] 配置 Levels（VIL/VIH/VOL/VOH/比较阈值）
- [ ] 配置 Timing（周期、驱动沿、采样沿）
- [ ] 加载并运行 Pattern
- [ ] 用 PMU 做一次 IV 扫描（开路/短路测试）
- [ ] 跑一次 Shmoo（VCC × 频率）
- [ ] 读结果文件、定位失败 pin 与失败周期

## 五、没有设备怎么练

| 方式 | 说明 |
|---|---|
| 厂商仿真/IDE | J750 有 IG-XL 仿真；V93000 有 SmarTest 仿真模式 |
| 培训机构 | 有真机的实操课，能摸到 Load Board 和 Handler |
| 开发板 + 仪器 | 用 FPGA/单片机模拟 DUT，用电源+示波器练"测"的思路 |
| 写程序代替跑程序 | 把测试流程写成 Python 仿真，理解"测什么、判什么" |
