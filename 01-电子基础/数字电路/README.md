## 必会的几个判断

1. **组合逻辑 vs 时序逻辑**：输出是否只取决于当前输入（有无记忆）。
2. **建立时间/保持时间**：数据必须在时钟沿前后稳定多久，违例会怎样（亚稳态）。
3. **竞争冒险**：为什么组合逻辑输出会出现毛刺，怎么消除。
4. **同步复位 vs 异步复位**：复位释放的时序风险。

## 与 ATE 的接口

- 功能测试 = 给输入向量（Pattern），比较输出是否符合预期（真值表/仿真结果）。
- Scan 测试 = 把触发器串成移位寄存器，用 Pattern 把内部节点"搬"到输出端观察。
- 时序配置 = 在 ATE 上定义每个 pin 的驱动沿与采样沿（Timing Set / Edge）。
