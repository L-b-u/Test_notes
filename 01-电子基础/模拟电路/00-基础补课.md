# 00 · 放大电路的前置知识

---

## 0. 需要补的知识点

| 要补的 | 为什么非补不可 |
|---|---|
| 电压、电流、电阻、欧姆定律 | 后面每一个公式都是它 |
| 回路（KVL） | 算 Q 点、算放大倍数的唯一工具 |
| 直流 / 交流、大小写约定 | 不懂这个，就看不懂 uBE 和 UBEQ 为什么是两个东西 |

| 三极管的三个工作区 | 不懂这个，就看不懂为什么要设 Q 点、为什么会失真 |

半导体物理（PN 结内部怎么导电）、运放、场效应管，这一章用不到，先跳过。

## 1. 电压、电流、电阻

**一句话**：电压是"推的力"，电流是"流过去的水"，电阻是"管子有多细"。三者满足 `U = I × R`。

- **电压 U**：两点之间的电势差，单位伏特 V。必须说"两点之间"，单独一个点没有电压。
- **电流 I**：单位时间流过截面的电荷量，单位安培 A。
- **电阻 R**：对电流的阻碍，单位欧姆 Ω。
- **欧姆定律**：`U = I·R`，三个量知道两个就能求第三个。

单位换算：

```
1 kΩ  = 1 000 Ω
1 mA  = 0.001 A
1 μA  = 0.000001 A
```

**练习**：12 V 加在 300 kΩ 两端，电流多大？

```
I = U / R = 12 / 300000 = 0.00004 A = 40 μA
```

> 注意：代入公式前先统一成 V、A、Ω，否则结果会差 1000 倍。

---

## 2. 串联、并联、分压

**一句话**：串联分电压、电流相同；并联分电流、电压相同。

```
串联：U总 = U1 + U2 + …      I 都一样      R总 = R1 + R2 + …
并联：I总 = I1 + I2 + …      U 都一样      R总 = R1·R2 / (R1 + R2)
```

**分压公式**（两个电阻串联，求 R1 上的电压）：

```
U1 = U总 × R1 / (R1 + R2)
```

例：5 V 加在 10 kΩ 和 20 kΩ 串联电路上，10 kΩ 上的电压是 `5 × 10/(10+20) = 1.67 V`。

> 这个公式以后在"分压式偏置"那一章会天天用；放大电路这一章的 Rb 就是一个"用 VCC 减去 0.7 V 之后落在 Rb 上的压降"。

---

## 3. 回路和 KVL

**一句话**：沿着一个闭合回路走一圈，电压升起来的量 = 电压降下去的量，加起来等于 0。

这是分析一切的**唯一工具**。举例：一个 5 V 电池接两个串联电阻。

```
从电池正极出发 → 经过 R1（电压降 U1）→ 经过 R2（电压降 U2）→ 回到负极
5 V = U1 + U2
```

三个使用要点：

1. **先画一个圈**（回路），再写等式。
2. 电源当作"电压升"，电阻、二极管、三极管两端当作"电压降"。
3. 放大电路要看两个圈：
   - **输入回路**：VCC → Rb → 基极 → 发射结 → 地 → 回 VCC
   - **输出回路**：VCC → Rc → 集电极 → 发射结（即 uCE）→ 地 → 回 VCC

把这两个圈写成等式，就是整个直流分析（算 Q 点）的全部内容。

> KCL（节点电流之和为 0）这一章基本用不到，知道有这么个东西就行。

---

## 4. 直流和交流，还有大小写约定

**一句话**：直流负责"把位置摆好"，交流负责"上下动"；大写字母写直流量，小写字母写瞬时总量。

| 写法 | 含义 | 例子 |
|---|---|---|
| 大写 `U`、`I` | 直流量（不随时间变） | `UBEQ = 0.7 V`，`ICQ = 1.88 mA` |
| 小写 `u`、`i` | 瞬时总量 = 直流 + 交流 | `uBE`、`iC`、`uCE` |
| 小写带下标 `e/be` | 纯交流分量 | `ube`、`ice` |
| 下标带 `Q` | 静默状态（没有信号时）的值 | `IBQ`、`UCEQ` |

三者的关系（**这一条必须记住**）：

```
uBE = UBEQ + ube        总电压   = 直流偏置 + 交流信号
iB  = IBQ  + ib
uCE = UCEQ + uce
```

**为什么放大器必须先有直流？**

三极管只有在"发射结正偏、集电结反偏"时才能放大，而这个状态要靠在基极上加一个合适的直流电流来维持——这就是**偏置**。

输入信号 ui 只有几毫伏到几十毫伏，本身根本"掰不动"三极管；它的作用是**在这个已经摆好的直流位置上，让电流上下浮动一点**。所以顺序永远是：

```
先有直流偏置（摆好 Q 点） → 再叠加交流信号（让它动） → 才有放大
```

**直流和交流怎么在同一张图里共存？** 靠电容隔开（见第 6 节）。

## 5. 正弦波：峰值、峰峰值、有效值、相位

**一句话**：描述一个正弦波，要三个数（幅度、频率、相位）。

- **峰值 Up**：从中心线到最高点的距离。
- **峰峰值 Upp**：最高点到最低点，`Upp = 2·Up`。示波器上直接量的是这个。
- **有效值 Urms**：正弦波 `Urms = Up / √2 ≈ 0.707·Up`。万用表交流档读的是有效值。
- **频率 f**：一秒钟几个周期；**周期 T = 1/f**。

**相位（phase）** 是这一章的重点：两个同频率的正弦波，比较"谁先到峰"。

```
同相：一起到峰、一起到谷          → 相位差 0°
反相：一个到峰时另一个正好到谷    → 相位差 180°（半个周期）
```

在示波器上判断：两条曲线**过零点同时同向**就是同相；**一个在最高点时另一个在最低点**就是反相。

> 放大电路里"输出与输入反相"，说的就是相位差 180°，不是"波形上下颠倒"这么模糊。

## 6. 电容：隔直通交

**一句话**：电容对直流相当于断路，对交流相当于通路——因为它只能"充放电"，不能"通过"。

- 直流加上去：电容很快充满，之后电流为 0 → **隔直**。
- 交流加上去：电压来回变，电容不停充放电，电流一直在流 → **通交**。
- 容抗（对交流的阻碍）：`XC = 1 / (2πfC)`。频率越高、容量越大，阻碍越小。
- 两个副作用要记住：
  1. **电容两端电压不能突变**（所以它能"锁住"直流电平）。
  2. 容量要够大才能当"短路"用：音频最低 20 Hz 时，`C = 10 μF` 的容抗约 800 Ω，还不够小；所以放大器里 C1、C2 常用几十 μF 的电解电容。

**在放大电路里的作用**：

| 电容 | 挡住什么 | 放过什么 |
|---|---|---|
| C1（输入） | 信号源自带的直流 | ui 的交流部分 |
| C2（输出） | 集电极的直流（UCEQ ≈ 几伏） | uo 的交流部分 |

如果去掉 C1，信号源的直流内阻会直接并到基极上，把 Q 点搞乱；去掉 C2，负载会把集电极的直流拉走，UCEQ 就变了。

## 7. 二极管：单向导电

**一句话**：正着接导通（压降约 0.7 V），反着接截止。

```
   阳极 ──▶|── 阴极
   正偏：导通，两端压降 ≈ 0.7 V（硅管）
   反偏：截止，几乎不导电
```

三极管的**发射结就是一个 PN 结**，所以：

```
UBEQ ≈ 0.7 V（硅管，导通时）
```

这就是 `IBQ = (VCC − 0.7) / Rb` 里那个 0.7 的来历——它不是随便规定的，是发射结的导通压降。

---

## 8. 三极管：三个脚、三个区、一个 β

**一句话**：基极一个小电流，控制集电极一个大电流；`iC = β·iB`。

### 8.1 三个脚

NPN 型，箭头朝外（发射极箭头方向就是电流流出的方向）：

```
        C（集电极）
        │
   B ───┤        ← 基极是一块很薄的区域
        │
        E（发射极）  ↗ 箭头朝外 = NPN
```

### 8.2 三个工作区（这一章的核心）

| 工作区 | 条件 | 电流关系 | 放大器的态度 |
|---|---|---|---|
| **截止** | 发射结反偏（uBE < 0.5 V 左右） | iB ≈ 0，iC ≈ 0 | 不能用，波形会被"削掉" |
| **放大** | 发射结正偏，集电结反偏 | `iC = β·iB`，随 iB 线性变化 | ✅ 放大器必须待在这里 |
| **饱和** | 两个结都正偏（uCE 降到 0.2~0.3 V） | iC 不再随 iB 增大，被"顶住" | 不能用，波形会被"削掉" |

**理解方式**：把三极管想成一个受基极电流控制的阀门。

- 基极电流太小（截止）→ 阀门全关，没有水流。
- 基极电流合适（放大）→ 阀门开度随基极电流线性变化。
- 开到底了（饱和）→ 再加大基极电流，阀门也不会开更大。

### 8.3 β 是什么

β 是电流放大倍数，常见 50~300。它表示"基极 1 mA，集电极能有 β mA"。

注意 β 不是一个稳定的常数：同一型号不同个体能差一倍，温度变了也会变。这一点直接导致后面要讲的"Q 点漂移"。

## 9. Q 点、直流通路、交流通路

**一句话**：Q 点是"没有信号时的静态工作点"；直流通路算 Q 点，交流通路算放大倍数。

### 9.1 Q 点

没有输入信号时，三极管各处的电压电流是固定的：

```
IBQ ≈ 几十 μA       ICQ ≈ 几 mA       UCEQ ≈ 几 V
```

这三个数就是 Q 点的坐标。**Q 点定得好不好，决定波形会不会失真。**

### 9.2 直流通路 vs 交流通路（分析任何放大器都是这两步）

| | 怎么画 | 用来算什么 |
|---|---|---|
| **直流通路** | 电容**开路**，交流信号源置 0 | Q 点（IBQ、ICQ、UCEQ） |
| **交流通路** | 电容**短路**，直流电源**置地** | 放大倍数、输入输出电阻 |

**为什么直流电源 VCC 在交流通路里要接地？**

理想电压源的端电压恒定不变。既然"不变"，那它对交流来说就相当于"电压永远为 0 变化"——两端之间没有交流电压，等价于用一根导线连到地。所以交流通路里 Rc 的上端是接地的、Rb 的上端也是接地的。

（这一步想不通，后面算输入电阻 Ri = Rb ∥ rbe 就会莫名其妙。）

## 10. 示波器：会接、会看相位就行

| 操作 | 说明 |
|---|---|
| 接探头 | 接地夹接电路 GND，探针接测试点；**接地夹一定要接**，否则波形是噪声 |
| 触发 Trigger | 选边沿触发、调触发电平，波形才会稳定不飘 |
| 耦合方式 | **DC 耦合**：看到全部电压（绕 UCEQ 摆）；**AC 耦合**：只看到交流部分（绕 0 摆） |
| 量峰峰值 | 用光标（Cursor）或自动测量 |
| 看相位 | 双通道：CH1 接输入、CH2 接输出，看两条曲线峰谷是否相反 |

> 记住这个：**同一个 uCE，示波器用 DC 耦合看是"围着几伏上下摆"，用 AC 耦合看是"围着 0 上下摆"。** 两种情况都对，只是看到的成分不同。

## 11. 自检题

1. 12 V 加在 300 kΩ 上，电流是多少 μA？
2. 两个电阻 10 kΩ、20 kΩ 串联接 5 V，10 kΩ 上分到多少伏？
3. 用一句话说清 KVL 在电路里怎么用。
4. `uBE` 和 `UBEQ` 有什么区别？`uBE` 由哪两部分组成？
5. 为什么放大器必须先有直流偏置？
6. 已知正弦波峰值 2 V，峰峰值和有效值各是多少？
7. 示波器上两条曲线，一个在峰、一个在谷，相位差多少？
8. 电容为什么能"隔直通交"？为什么 C1 要用几十 μF？
9. 三极管三个工作区的条件分别是什么？放大器要工作在哪个区？
10. 交流通路里 VCC 为什么当地？直流通路里电容为什么开路？

<details><summary>参考答案</summary>

1. 40 μA。
2. 1.67 V。
3. 沿闭合回路走一圈，电压升之和 = 电压降之和。
4. `uBE` 是总电压（直流+交流）的瞬时值；`UBEQ` 只是它的直流部分。`uBE = UBEQ + ube`。
5. 三极管只有在放大区（发射结正偏、集电结反偏）才放大，这个状态要靠直流偏置维持；输入信号太小，不能自己建立工作点。
6. 峰峰值 4 V；有效值 2/√2 ≈ 1.41 V。
7. 180°。
8. 电容只能充放电、不能通过电荷：直流充满后电流为 0（隔直），交流不断充放电、电流一直存在（通交）。音频 20 Hz 时容抗要小，所以 C 要大。
9. 截止：发射结反偏；放大：发射结正偏、集电结反偏；饱和：两个结都正偏。放大器工作在放大区。
10. 理想电源电压恒定，对交流来说没有电压变化，等价于接地；电容对直流充满后不再导通，等价于开路。

</details>
