## 学习方法

- 模电**不要死磕数学**：ATE 岗只要"看得懂 + 会分析"。
- 每章都问自己三个问题：**这个电路干什么用？Q 点/工作点在哪？出问题会表现成什么样？**
- 公式只背"能推出结论的那个"，其余现场推。
