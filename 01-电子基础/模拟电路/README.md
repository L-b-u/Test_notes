## 图放在哪

**不做单独的图库目录**：每章的图直接以 `.svg` 放在与该章 md 相同的目录里，用相对路径引用，打开文档就能看到（GitHub、VS Code 预览都直接显示）。

为什么用 SVG 而不是截图：矢量图放大不糊、能直接改文字，也不用纠结版权。

## 我的学习规矩

1. 先看 [00-基础补课](00-基础补课.md)，补不上来就别硬看正文。
2. 每章正文里凡是出现"我卡住过"的地方，都单独写了 FAQ。
3. 每个电路自己手画一遍，每个例题自己手算一遍。
4. 公式只背"能推出结论的那一个"，其余现场推。
