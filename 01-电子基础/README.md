## 为什么 ATE 岗必须学这两门

- **数电**：Scan、BIST、功能测试、Pattern，全部建立在"门电路 + 触发器 + 时序"之上。看不懂时序图，就调不出 Pattern。
- **模电**：DC 参数测试（阈值、漏电、驱动能力）、AC 参数测试（增益、带宽、噪声）、电源类测试，全部要用到放大电路、运放、频响的知识。
- **器件物理**：知道 PN 结和 MOS 的工作区，才理解为什么某项参数要这样测、失效模式为什么长这样。

## 本阶段的学习方法

1. **先看整章视频，再回头精读**：第一遍看结构，第二遍动手。
2. **每个电路手画一遍**：不看原图画，画完对照。
3. **每个例题手算一遍**：数字自己代，算完检查量级是否合理。
4. **每章写一页速记卡**：写不出来 = 没学会。
